# 🐾 Интерактивное приглашение на свидание с пиксельным котиком

Милый, романтичный и отзывчивый веб-сайт для приглашения девушки на свидание с интерактивным пиксельным котиком, анимированными лапками выбора и игровыми механиками.

## ✨ Особенности проекта

1. **Компонент выбора «Кошачья лапка» (Cat Paw Toggle)**:
   - Полная интеграция и модернизация предложенного компонента: вместо сердечка создана детальная векторная лапка котика с подушечками (toe beans).
   - Плавная анимация наполнения цветом (`keyframes-svg-filled`) с упругим отскоком.
   - Эффект всплеска искр (`keyframes-svg-celebrate`) при выборе.
   - Полная адаптивность (`clamp()`, тач-зоны от 48px, поддержка клавиатуры и скринридеров).

2. **Живой пиксельный котик с анимациями**:
   - Четкая векторная пиксельная графика (`image-rendering: pixelated; shape-rendering: crispEdges;`).
   - Естественное дыхание, покачивание хвостика, моргание глаз и светящийся румянец на щечках.
   - Интерактивные состояния:
     - **Idle**: котик спокойно ждет и моргает.
     - **Excited**: при наведении на «Да» у котика светятся глаза, ускоряется хвост и появляется сердечко над головой.
     - **Pleading**: при попытке навести на «Я подумаю» котик делает большие умоляющие глазки и жалобно мяукает в облачке мыслей.
     - **Celebration**: при согласии котик радостно подпрыгивает в танце.
     - **Реакция на ласку**: можно кликнуть на котика — он замурлычет и выпустит фонтан сердечек.

3. **Игровая кнопка-убегайка («Я ещё подумаю... 🙈»)**:
   - При приближении курсора или пальца кнопка игриво отпрыгивает с забавными фразами.
   - На 4-ю попытку превращается в кнопку согласия «Ладно, уговорил, ДА! 💖».

4. **Выбор вариантов свидания**:
   - 6 карточек с лапками: кофейня, киновечер, прогулка, вкусный ужин, панорамный вид, секретный сюрприз.
   - Выбор удобного дня и поле для любимого десерта / пожелания.

5. **Золотой VIP-билет и мгновенная отправка ответа**:
   - Генерирует стильный билет с перфорацией и уникальным номером.
   - Кнопка отправки готового сообщения в **Telegram** с выбранными пунктами.
   - Кнопка отправки в **WhatsApp**.
   - Кнопка копирования текста в буфер обмена с всплывающим уведомлением.

6. **Аудио-синтезатор (Web Audio API)**:
   - Все звуковые эффекты (мурлыканье, клик лапки, фанфары «Да!», отпрыгивание кнопки) генерируются в реальном времени. Никаких внешних mp3-файлов, которые могли бы не загрузиться или заблокироваться политикой CORS.
   - Кнопка включения/выключения звука в правом верхнем углу.

## 🚀 Как запустить проект

### Вариант 1: Открыть напрямую в браузере
Просто дважды кликните по файлу `index.html` или откройте его в любом современном браузере (Chrome, Edge, Safari, Firefox).

### Вариант 2: Локальный сервер
Вы можете запустить локальный сервер в папке проекта:
```bash
# Через Python:
python -m http.server 8000

# Или через Node.js:
npx serve
```
И откройте в браузере адрес: `http://localhost:8000`.

## 💌 Как персонализировать для своей девушки

В файле `index.html`:
- Строка 247: замените заголовок `<h1>Ты пойдёшь со мной на свидание?</h1>` на персональный (например: `<h1>Алиса, пойдёшь со мной на свидание?</h1>`).
- Строка 50: в облачке мыслей котика можно написать ваше ласковое прозвище для неё.
- В секции карточек (строки 270–420) вы можете отредактировать названия и описания мест, куда именно вы хотите её пригласить.
